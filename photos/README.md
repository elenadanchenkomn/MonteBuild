# Фото и видео для блога и соцсетей

Сюда загружаются **свои** фото и видео с объектов. Из них автоматически собираются статьи на montebuild.com и посты в Facebook и Instagram.

## Как загрузить
1. Откройте нужную папку на github.com (можно с телефона, в браузере).
2. **Add file → Upload files**, перетащите фото, внизу нажмите **Commit changes**.

## Папки
| Папка | Что класть |
|---|---|
| `plesen/` | плесень, сырые углы, конденсат, обработка, влагомер в кадре |
| `steny/` | шпатлёвка, шлифовка, покраска, стены в боковом свете (Q2–Q4) |
| `shtukaturka/` | венецианская и декоративная штукатурка |
| `elektrika/` | проводка, щиты, розетки |
| `dekor/` | молдинги, рейки, декоративные панели на стенах |
| `potolki/` | потолки: шпатлёвка, многоуровневые, теневой шов |
| `gipsokarton/` | короба и стены из ГКЛ, влагостойкий ГКЛ |
| `interery/` | готовые интерьеры «после» (без людей и личных вещей) |
| `instrumenty/` | инструменты в работе (для рубрики «Инструмент в кадре») |
| `video/` | вертикальные видео 15–60 с для Reels (mp4, до 100 МБ) |
| `obekty/` | кейсы: **одна подпапка на объект**, внутри фото «до/после» и файл `info.txt` |

### Кейсы (`obekty/<название-объекта>/info.txt`)
Без этого файла кейс не публикуется — задача не придумывает цифры. Пример:
```
Район: Новый бульвар
Площадь: студия 32 м², стены 85 м²
Работы: удаление плесени, шпатлёвка Q3, покраска
Срок: 9 дней
Стоимость работ: 4 200 ₾ (без материалов)
Что было сложного: после прошлой бригады стены были в волнах, пришлось снимать слой
Можно ли называть ЖК: нет
```

## Важно
- Репозиторий публичный: **никаких лиц, номеров квартир, документов, адресов** в кадре.
- Имена файлов любые. Использованные фото записываются в `content/used_photos.json`, повторно на обложку они не идут.
- Если новых фото нет, задача берёт фото, которые уже есть на сайте.
